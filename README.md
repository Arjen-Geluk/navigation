# Navigatie

Vaargebieden en wedstrijdberekeningen van Arjen Geluk.

Online overzicht: https://arjen-geluk.github.io/navigation/

## Inhoud

- [`getijkaart/`](getijkaart/) — Getijkaart Waddenzee: bodemhoogte en waterstand met tijdschuif, route-export voor OpenCPN.
- [`3-stedenrace/`](3-stedenrace/) — Klipperrace 3 Steden: routeringstool met polair diagram en kruisslagen-voorstel.
- [`polartool/`](polartool/) — Polartool: polar voor een platbodem opbouwen uit handmatige waarden en VDR-logs van OpenCPN.
